## Description
### The Biological Problem

Hydrophobicity is a key factor in understanding protein structure, function, and interactions. One of the primary determinants of protein folding is hydrophobic character as hydrophobic amino acids tend to cluster near the center of a protein, away from water [(Alberts, 1970)](https://www.ncbi.nlm.nih.gov/books/NBK26830/). This folding is what creates the 3D structure of a protein, and the presence of hydrophobic amino acids enables a protein to participate in hydrophobic interactions. One reason hydrophobic interactions are important is because they play a crucial role in stabilizing drug-receptor interactions [(Ferreira de Freitas & Schapira, 2017)](https://pubs.rsc.org/en/content/articlehtml/2017/md/c7md00381a). Over 40% of drugs used in clinical settings are hydrophobic, as well as approximately 90% of new drugs in development[(Hogarth et al., 2021)](https://pubs.rsc.org/en/content/articlehtml/2021/tb/d1tb02297k); [(Trafton, 2021)](https://news.mit.edu/2021/nanoemulsion-drug-formulation-pills-0607#:~:text=About%2060%20percent%20of%20drugs,absorbed%20by%20the%20human%20body.). Hydrophobic portions of a drug tend to bind to hydrophobic regions within the binding sites of target proteins. Another type of interaction that stabilizes drug-receptor interactions are pi-pi interactions. Some amino acids, specifically those with aromatic side chains, are able to participate in pi-pi interactions.

### What is this project?

A Python 3 command-line tool that processes protein sequences from a FASTA file, calculates their amino acid composition and average hydrophobicity using the Kyte-Doolittle scale, and generates visualizations (histograms, bar charts) and a summary CSV file. It accepts user-specified parameters via command-line arguments and saves output to a designated directory.

### Why is this project relevant?

By calculating average hydrophobicity, this project can help researchers predict whether a protein/protein region is likely to participate in hydrophobic interactions. This will enable researchers to design drugs that have complementary regions of hydrophobicity, or select existing drugs with hydrophobic regions that complement the target protein, to enhance binding affinity as well as specificity. By calculating amino acid composition, researchers will be able to quantify specific amino acids in a sequence. Knowing this information will enable researchers to identify candidate proteins with sufficient amino acids containing aromatic side chains that can engage in pi-pi interactions with drugs in development, further strengthening binding affinity and/or specificity.

## Usage

To run the script, use the following command:

```bash
python3 main.py --fasta_file <fasta_file_path> [--output_dir <output_directory>] [--parameter <top_n_sequences>]
```
### Options

`--fasta_file` or `-f` (required): Path to the input FASTA file containing amino acid sequences to be analyzed.

`--output_dir` or `-o` (optional): Path to the directory where output files (visualizations and CSV file) will be saved (Default: `output/`).

`--parameter` or `-p` (optional): The number of top and bottom sequences to report in the generated CSV file (Default: `1`).

### Example 
```bash
python3 main.py --fasta_file sequences.fasta --output_dir results/ --parameter 5
```
This command will analyze the sequences in `sequences.fasta`, save the results in the `results/` directory, and highlight the top 5 and bottom 5 sequences based on their hydrophobicity in the CSV output.

## Required Input
The main required input is a FASTA file containing one or more protein sequences composed of standard amino acid codes.

## Expected Output
When the script runs successfully, the following output will be saved in the specified output directory (default: `output/`):

#### Visualizations:

- Amino Acid Frequency Histograms: One PNG file per amino acid (e.g., `aa_frequency_A.png`, `aa_frequency_L.png`, etc.).

- Average Hydrophobicity Bar Chart: `average_hydrophobicity.png`-- A bar chart showing the average hydrophobicity value for each sequence.

- Summary CSV File: `average_hydrophobicity.csv`--A table listing:
	- Sequence names
	- Their average hydrophobicity scores
	- The top N and bottom N sequences based on hydrophobicity

***Output files are saved automatically in the directory you specify with `--output_dir`.***

## Data Plan
### General Data Sources

The data for this project will come from any protein FASTA file that the user provides as input. The script processes the provided FASTA file to analyze the amino acid composition and hydrophobicity values of the sequences it contains. Users can input their own FASTA files, and the script will perform the same analysis, generating results and visualizations accordingly.

### Example Data
For the specific example used in this project, the data is a reference proteome for ***Human adenovirus 4a***. The proteome consists of 34 proteins and is sourced from [UniProt](https://www.uniprot.org/) (Proteome ID: UP000326129). This dataset was chosen to demonstrate the functionality of the analysis tools in the script.

The reference proteome can be downloaded from the following link:
[Human adenovirus 4a proteome (UP000326129) on UniProt](https://www.uniprot.org/proteomes/UP000326129)

### Biological Relevance
The analysis of this proteome can be particularly relevant in the context of antiviral drug research. By studying the amino acid composition and hydrophobicity profiles of the proteins in the ***Human adenovirus 4a proteome***, researchers can identify key protein targets that may be involved in the ability of the virus to infect host cells. Understanding the structural properties of these proteins can aid in the design of drugs that target critical viral proteins, potentially leading to more effective antiviral therapies. Additionally, the hydrophobicity analysis may provide insights into the protein-ligand interactions that are crucial for drug binding, offering a deeper understanding of how to design molecules that can effectively interfere with viral processes.
